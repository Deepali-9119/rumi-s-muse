# Rumi's Muse

help me create a web app "RumiIsYourRoomie" that allows a user to submit a topic or a situation, and the app returns a poem about it in typical Rumi (the poet) style. Use the attached images as design inspiration. The app should have a simple structure, with only 1 field to take input from the user, just like a chatbot. I want to connect this site to it's backend logic in n8n through this webhook:  https://shoot-sept-distribution-championship.trycloudflare.com/webhook-test/307bd27c-c693-4c85-98e2-241a1909a633

Idea is that the topic entered by the user is sent to this webhook, and it's response (a poem about the topic) is showcased in a beautiful poetry format to the user.
